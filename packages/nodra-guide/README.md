# nodra-guide

Skill for Claude Code, Codex and OpenCode that teaches the assistant to use Nodra: the CLI, package sources, packaging, Works nodes, MCP servers, bots and the Claude Code marketplace. Everything is offline: the skill carries a self-contained guide (`skills/nodra-guide/offline.md`) and points at the `docs/` folder of your Nodra checkout for the full reference.

```sh
nodra install nodra-guide
nodra uninstall nodra-guide --force
```

`nodra welcome` installs it, together with `nodra-package`, for the AI tools it detects.
